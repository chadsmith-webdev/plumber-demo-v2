# Plumber Website Demo

This is a multi-page demo website for a fictional plumbing company, "Ozark Plumbing Co.".

## Pages

- **Home:** Main landing page with a hero section, services overview, testimonials, and gallery.
- **Services:** A detailed list of all plumbing services offered.
- **About:** Information about the company, its history, and team.
- **Contact:** A contact form and other contact information.

## Tech Stack

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (for mobile navigation and animations)
- [Heroicons](https://heroicons.com/) for icons
- [Google Fonts](https://fonts.google.com/) for typography

## How to Run

Simply open the `.html` files in your web browser.
